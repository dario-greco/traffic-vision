# BDD10k 10k Subset Data
This folder is intentionally ignored by Git to avoid uploading large image files.

### Setup Instructions for Teammates:
1. Obtain the `bdd_subset_10k.zip` file.
2. Unzip it directly into this `data_final/` directory.
3. Ensure your structure looks like this:
   - `data_final/images/train/`
   - `data_final/images/val/`
   - `data_final/labels/train/`
   - `data_final/labels/val/`
